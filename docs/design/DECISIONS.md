## 2026-10-31 · Little Joy, Well Organized

**상태: 사용자가 지정한 브랜드 방향을 문서 기준으로 채택. 실제 화면 리디자인은 별도 승인 전.**

Playful Minimalism을 채택한다. 차곡의 밝고 사랑스러운 인상은 유지하되, 장기간 수집하고 요리하며 읽는 도구에 맞게 정보 위계와 정돈된 화면을 우선한다. 정갈함 80%·작은 즐거움 20%는 정성적 기준이다.

| 항목 | 이번 결정 | 이유·적용 경계 |
| --- | --- | --- |
| 노랑 | `#FFE27B` → 제안 `#F4C84B` | 병아리 노랑 정체성을 유지하되 버터 옐로로 조정. 채움 사용량을 줄여 주요 행동에 집중 |
| 배경 | `#FFFDF7` → 제안 `#FFFEFB` | 종이 느낌은 약하게 남기고 사진과 텍스트의 중립 배경 확보 |
| 귀여움 | 반복 캐릭터·파스텔·테이프 대신 작은 선택/빈 상태 디테일 | 이전 ‘귀여움 유지’를 제거가 아닌 사용량 제한으로 구체화 |
| 폰트 | Pretendard를 차기 기본 후보로 권장 | 둥근 본문 인상을 줄이고 한글·영문·단위의 정보 전달에 집중. 나눔스퀘어라운드 교체는 시안 승인 후 |
| 카드/목록 | 두 뷰와 기존 선택 기억 유지 | 이전 승인한 탐색 경험을 보존하고 스타일만 개선 |
| 로고 | 기존 자산 보존, 최종 확정 보류 | 본문 폰트와 브랜드 자산 변경을 혼동하지 않음 |
| 구조 | 현재 공통 컴포넌트·CSS 재사용 | 새로운 UI 프레임워크나 불필요한 의존성 없이 개선 |
| 접근성 | 강조 배경 전용 보조 글자색·진한 경계 추가 | 제안 팔레트만으로 모든 조합의 AA 대비를 확보할 수 없으므로 의미 토큰 보완 |

### 이번 단계에서 한 일

소스·기존 검증 캡처·과거 승인·폰트 로딩 방식 분석, 기존/제안 색상 비교와 단색 대비 계산, 시스템/에이전트 지침/검토 스킬 작성, 우선순위와 대표 화면의 구조 제안.

### 다음 승인에서 정할 일

보관함을 첫 대표 화면으로 삼아 새 팔레트·반경·Pretendard 400/600·사진 없는 구성과 선택 강조량을 같은 콘텐츠로 검토한다. 방향을 승인받은 뒤 보관함 → 상세 → 등록·수정 → 로그인/안내 순으로 실제 화면 변경 범위를 정한다.

분량 자동 계산·무한 스크롤·좌측 제목 목차·단계 이동·버전/수정 이력·평가 등 새 기능은 디자인 가이드의 장기 방향이며 이번 문서 작업의 구현 대상이 아니다. 기존 계획은 유지한다.
