# 디자인 비교 시안 검증 · 2026-10-18

대상은 `docs/design/34/`의 정적 시안이다. 앱의 인증·DB·저장 구현 검증이 아니다.

## 실행 결과

- `node --check docs/design/34/preview.js`, `git diff --check` 통과.
- Chromium에서 A/B × 보관함/상세/입력 × 320/390/768/1440px, 총 24개 조합의 `document.documentElement.scrollWidth <= innerWidth` 확인.
- 320/1440px의 12개 전체 화면 캡처 후 주요 모바일·PC 화면을 시각 점검. 최초 점검에서 찾은 HTML의 literal `\n`과 모바일 B 썸네일 문구 잘림을 수정하고 재캡처했다.
- 검색 1건, 빈 결과, 전체 보기 복귀, 즐겨찾기 필터, 시안 전환 시 입력 보존, 화면 왕복 시 입력 보존, 실제 저장하지 않았다는 안내, 기존 GowunPreview 파일 로딩을 브라우저에서 assert로 확인했다.
- 최초 검증 스크립트는 label을 `제목`으로 정확히 일치시켜 `제목 필수`를 찾지 못하고 timeout 됐다. 실제 접근 가능한 이름에 맞춰 수정한 뒤 8개 assertion 통과. 제품 결함으로 처리하지 않았다.
- Pretendard/Noto Sans KR/기존 고운돋움의 FontFaceSet loaded 상태를 확인했다. 외부 웹폰트 로딩 완료 후 캡처했다.
- 24개 화면의 가로 넘침 확인은 수정 후 재실행했다. 캡처는 이 문서와 같은 폴더의 `screens/`에 보관한다.
