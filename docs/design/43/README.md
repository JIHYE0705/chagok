# 보관함 대표 시안 · #43

2026-11-07 · 기준 `38fa696` · **제안 상태, 실제 앱 미적용**

[디자인 시스템](../DESIGN_SYSTEM.md)과 [결정 기록](../DECISIONS.md)의 Playful Minimalism 방향을 HTML로 검토한다. 같은 네 항목을 카드형·목록형으로 전환하고, 현재 나눔스퀘어라운드 400/700과 후보 Pretendard 400/600을 비교할 수 있다. 이 시안의 승인과 앱 구현 완료는 별개다.

## 열기

이 브랜치의 저장소 루트에서 실행한다.

```sh
python3 -m http.server 8043 --bind 127.0.0.1
```

브라우저: <http://127.0.0.1:8043/docs/design/43/>

검색 제출·태그·즐겨찾기·초기화·보기 전환·폰트 비교·긴 제목 전체 보기를 눌러볼 수 있다. 데이터는 페이지 메모리에만 있고 새로고침하면 초기화된다. 실제 앱의 뷰 기억 쿠키를 건드리지 않는다. 로그아웃·등록·태그 편집은 연결하지 않고 안내만 제공한다. 페이지가 네 항목뿐이라 다음 페이지 이동은 표시하지 않았다.

## 제안

- Warm White 배경, Charcoal 본문, Butter Yellow의 주요 행동과 선택 표시. 검색 영역은 중립화한다.
- 최대 폭 1160px, 카드 10px·버튼 8px, 그림자 없는 구조. 3열 → 2열 → 1열로 바뀐다.
- 제목을 먼저, 날짜·종류·태그는 아래 보조 정보로 배치한다. 목록 제목은 표시만 두 줄로 제한한다.
- 사진 없는 카드의 큰 캐릭터 표지를 없애고 얇은 중립선과 텍스트를 사용한다. 목록형은 사진 있는 항목만 작은 표지를 둔다.
- 320px에서 제목과 등록 버튼을 같은 행, 검색 필드와 검색 버튼을 같은 행에 놓아 결과까지의 높이를 줄인다. 필터를 숨기지 않는다.
- Pretendard를 본문 후보로 권장한다. 기존 워드마크 SVG는 그대로 비교한다. 시안에 상세/등록 기능이나 새 정렬 기능은 추가하지 않았다.

## 자산과 한계

Pretendard는 [공식 v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/static/woff2)의 정적 Regular/SemiBold를 내려받아 로컬 제공하며 [OFL](fonts/OFL.txt)을 동봉했다. 현재 폰트는 기존 앱 파일을 참조한다. 외부 폰트 CDN·추가 패키지는 없다.

| 후보 | 실제 파일 바이트 |
| --- | ---: |
| 정적 400 | 765,892 |
| 정적 600 | 785,856 |
| 정적 합계 | 1,551,748 |
| 가변 WOFF2 (비교 다운로드만, 저장소 미포함) | 2,057,688 |

필요한 두 굵기의 정적 합계가 작아 시안에 사용했다. 이는 파일 크기 비교이며 전송량이나 성능 개선 측정이 아니다. 실제 앱 적용 시 subset·fallback·preload와 느린 로딩 CLS를 별도 확인한다.

사진은 기존 #34 시안의 [우리의식탁 땡초김밥](https://wtable.co.kr/recipes/314wwQZR5hXP4RMCEKzJMHfa) 외부 이미지를 출처와 함께 재사용했다. 원본 사진 파일은 저장소에 복제하지 않았다. 네트워크/출처 정책에 따라 표시되지 않을 수 있으며 이 경우 안내로 대체한다. 나머지 세 항목은 텍스트 표시 예시다. 실제 계정의 데이터나 검증된 조리 정보가 아니다.

## 검토할 결정

1. 사진 없는 카드의 짧은 텍스트 구성과 목록형의 사진 유무에 따른 들여쓰기가 편한가?
2. Pretendard의 정보 전달과 현재 폰트의 둥근 인상 중 어느 쪽이 차곡에 맞는가?
3. 노란색 사용량과 모바일 검색/필터의 밀도가 적절한가?

방향을 확인한 후 실제 보관함과 공통 스타일의 구현 범위를 정한다. 상세·등록/수정·로그인과 새 기능은 후속 범위다. 이 문서는 승인 기록을 대신하지 않는다.
