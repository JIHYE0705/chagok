# Google OAuth 로컬 검증

- 일자: 2026-10-10 (Asia/Seoul)
- 대상: PR #18이 병합된 `main` (`776b0cd`), 연결된 Supabase 개발 프로젝트
- 앱 주소: `http://localhost:3000`
- 방법: 사용자가 본인 브라우저와 실제 Google 계정으로 직접 검증

## 확인한 결과

- Supabase 공개 Auth 설정 API가 정상 응답했고 Google 제공자가 활성화돼 있었다.
- `APP_URL=http://localhost:3000`을 지정해 앱을 실행했고 `/login`이 HTTP 200으로 응답했다.
- 사용자는 Google 로그인 후 보관함 진입에 성공했다고 보고했다.
- 새로고침, 로그아웃 후 접근 차단, 재로그인 확인을 안내한 뒤 사용자가 추가로 정상 동작을 보고했다. 각 단계의 개별 결과는 따로 수집하지 않았다.

서버 프로세스가 종료돼 접속되지 않았던 경우에는 서버를 재시작하고 정상 응답을 확인했다. 인증 코드 변경이나 OAuth 설정 변경은 없었다.

## 남은 확인

- 새로고침·재접속, 로그아웃 후 접근 차단, 재로그인의 개별 결과 기록
- 미허용 실제 Google 계정 접근 거부
- Google 로그인 취소 및 OAuth 오류
- 실제 모바일과 PC의 각각의 로그인·콜백 결과
- Google Cloud와 Supabase 대시보드 설정의 직접 확인

합성 Google identity 기반 자동 검증은 실제 계정 검증과 구분한다. 위 미확인 항목 때문에 #4를 종료하지 않는다. 계정 식별자, 인증키, 토큰, 개인 프로필 원문은 이 기록에 포함하지 않는다.
